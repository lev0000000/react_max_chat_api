#Интеграция чатов и Max (запуск на Windows)

1. Клонируйте репозиторий к себе на компьютер, или скачайте и разархивируйте.
2. Откройте проект в IDE и перейдите в терминал и выполните команды:
   cd .\max-green-api
   npm install
   Copy-Item .env.example .env
   npm run dev
3. Если ошибка доступа то попробуйте запустить IDE или терминал от имени администратора.
4. После этого проект запустится, перейдите по ссылке указанной в терминале, например http://localhost:5173
5. Введите свои данные.
6. После авторизации откроется интерфейс чатов.
7. Слева можно ввести номер контакта.
8. Снизу отображаются все контакты, по ним можно перейти и попасть в чат.
